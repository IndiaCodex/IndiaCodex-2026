# 🔒 TrustLock

## Problem Statement

Hiring freelancers online involves trust issues.

• Clients fear paying before receiving quality work.

• Freelancers fear delivering work without getting paid.

TrustLock solves this using an escrow-based workflow with dispute resolution.

---

## Features

✅ Secure Escrow Creation

✅ Client Dashboard

✅ Freelancer Dashboard

✅ Agent Dashboard

✅ Project Status Tracking

✅ Preview Upload

✅ Approve / Dispute Workflow

✅ Refund & Release Process

---

## Workflow

Client Creates Project

↓

Money Locked in Escrow

↓

Freelancer uploads Preview

↓

Client Reviews

↓

Approve → Release Payment

OR

Dispute → Agent Reviews

↓

Refund or Release
