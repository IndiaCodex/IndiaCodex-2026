# Slide 2 — The Problem

## Title

Nobody can prove what an agent actually did

## Content

Three questions almost no team can currently answer:

- **Why did this payment happen?** — an agent made a Masumi payment; the
  counterparty disputes it three weeks later.
- **Why did the agent make this decision?** — the reasoning lived in a chat
  log that's since scrolled away or was never saved at all.
- **Can you prove this record wasn't altered?** — "trust our database" is
  not an answer an auditor accepts.

## Speaker Notes

Make it concrete, not abstract: "Imagine an autonomous agent renews a
subscription through Masumi. The payment gets disputed a month later. Someone
asks your team: why did the agent do this, and can you prove it? Today, most
teams have nothing but scattered application logs — no cryptographic proof
the record wasn't edited, and no way to replay the run without calling a
live LLM again, which by now might answer differently." Land on: "Sentinel
exists to make those three questions answerable, deterministically, every
time."

## Visual Suggestions

Three stacked cards styled like support-ticket quotes, each showing one
unanswerable question in quotation marks. Muted, slightly desaturated red
accents — this is the "before" slide, tension not resolution.
