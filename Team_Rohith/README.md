# Team Rohith - Decentralized AI Productivity App

A decentralized, AI-powered productivity application integrating Cardano wallet authentication (CIP-30), Google Services, an AI chat interface with RAG capabilities, and secure document management.

## Tech Stack
- **Frontend:** Next.js, React, Tailwind CSS, MeshSDK
- **Backend:** FastAPI, Python, Firebase, NVIDIA LLaMA

## Getting Started
1. Run backend: `uvicorn main:app --reload`
2. Run frontend: `npm run dev`
