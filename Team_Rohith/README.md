# 1. Project Name
**LifeVault**

# 2. Project Description
LifeVault is a next-generation, AI-powered productivity application designed to give users absolute control over their personal data, schedules, and documents. By bridging Web3 security with cutting-edge AI, LifeVault transforms how users interact with their digital lives. It securely stores files, automatically extracts key lifecycle events (like warranty expirations or contract renewals) using AI, and autonomously synchronizes them with the user's master calendar and communication channels (Slack/Email).

# 3. Problem Statement
In the modern digital age, users are overwhelmed by fragmented data. Important documents (like warranties or contracts) expire without notice, calendar events get lost in the noise, and personal data is locked behind centralized, unsecure storage providers. Users lack a unified, secure system that can actively read their documents and manage administrative overhead for them.

# 4. Tech Stack
- **Frontend:** Next.js 16 (App Router), React, Tailwind CSS, Framer Motion
- **Backend:** FastAPI (Python), Uvicorn
- **Database:** Firebase / Firestore
- **Web3:** MeshSDK for Cardano CIP-30 Authentication (Wallet signing for decryption)
- **AI Integration:** NVIDIA LLaMA Vision & Text Models (RAG pipelines)
- **Integrations:** Google OAuth (Calendar, Gmail, Drive)
